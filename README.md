## 素材從哪來
- 丁丁 0912 的 25 支幹話 Log 毛片都看過：外盒只出現在書櫃背景（C0059、C0061），沒有擺出來的鏡頭。
- 外盒畫面只在丁丁 11/19 交的「幹話日曆(版本1).mp4」（Google 雲端，已壓字幕、沒有乾淨毛片）。本機用 `01_廣告投放/幹話日曆/成片/丁丁廣告_1120/11.20丁丁④幹話_笑點開頭_v6.mp4`（取自版本1）：
  - 推盒：12.567–15.133 秒，裁掉上方「推出3款不同外觀、也不同色的外盒」字；天藍、薄荷放慢 0.65 倍讓三色停留時間接近。
  - 抱三盒：8.05 秒（笑臉、手和盒子都清楚；8.2 秒後開始揮手會糊），裁掉上方「我們推出了超調皮的」字，帽子完整。
- 沒用的：拿日曆＋外盒「非常適合送給朋友」（盒子失焦、表情是張大嘴）、三盒疊在桌上（字壓到帽子）、俯拍三盒（字壓在盒子上）。

## 待確認
- 旁白條「外盒跟底座同色」是看影片推斷的（推盒時後面日曆的底座顏色跟著外盒換），請確認實際出貨是不是這樣配。
- 想要更清楚的禮盒畫面，可以跟丁丁要版本1 的乾淨毛片（沒壓字），就能用俯拍三盒那段。
